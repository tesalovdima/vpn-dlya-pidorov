# League of Legends через VPN: что настроено и как проверить

## Что уже сделано для LoL

| Требование LoL | Как решено |
|---|---|
| Игра не понимает SOCKS/HTTP-прокси | VPN работает как **обычное сетевое подключение Windows** (L3-туннель) |
| Игровой трафик идёт по **UDP** (порты 5000–5500) | L2TP/IPsec передаёт UDP нативно, без «UDP-over-TCP» |
| Фризы и «резиновый» персонаж | MTU 1300 внутри туннеля + MSS-clamping 1240 на сервере |
| Скачки пинга | BBR + fq на сервере, MSS-clamping |
| Vanguard/античит | VPN — обычный сетевой адаптер Windows, драйвер подписан Microsoft |

## Как включить

1. Правый клик по значку сети в трее → **MyVPN** → **Подключить**
   (или `rasdial "MyVPN" vpnuser <ПАРОЛЬ>`).
2. Убедиться, что внешний IP сменился:
   ```powershell
   curl.exe https://api.ipify.org
   ```
3. Запускать Riot Client / LoL **после** подключения VPN.

Отключить: значок сети в трее → MyVPN → **Отключить** (`rasdial "MyVPN" /disconnect`).

## Проверка, что UDP реально ходит через туннель

```powershell
# пока VPN подключён:
Resolve-DnsName www.google.com -Server 8.8.8.8 -Type A -DnsOnly
```

Если отвечает — UDP через туннель работает (DNS-запрос идёт по UDP).

Проверка пинга до игровых серверов:

```powershell
Test-Connection lol.secure.dyn.riotcdn.net -Count 4
```

## Подбор сервера по пингу

Пинг в LoL = пинг до VPN + транзит с VPN до серверов Riot.

* EUW/EUNE (Амстердам/Франкфурт) — берите VPS в Германии/Нидерландах.
* Для игры важны потери пакетов: выбирайте хостер с нормальным транзитом.
* Комфортным считается +10…+40 мс к «прямому» пингу.

## Если игра не видит сеть

1. Проверьте, что подключение действительно **Connected** и внешний IP сменился.
2. Уменьшите MTU: на сервере `--mtu 1250`, затем переустановите подключение.
3. Посмотрите логи сервера: `journalctl -u xl2tpd -n 50`.
4. Другие VPN-клиенты (Windscribe, Shadowsocks, Zapret) — лучше выключить,
   чтобы не было конфликтов маршрутизации.

## Пинг «скачет» вечером

Это перегрузка транзита провайдера, а не VPN. Помогает:
* другой регион/хостер сервера;
* включённый BBR (включён скриптом установки);
* в настройках LoL отключить «Передавать голос» / снять фоновые загрузки.
